# 📒 Personal Notes App
Single-file PHP + MySQL notes keeper application.

## ✨ Features
- Add notes with custom colors
- Auto-saves date & time
- Delete notes
- Fully responsive design
- Auto-setup — no manual SQL needed

## 🖥️ Run Locally (XAMPP)
1. Place `app.php` in `htdocs/project/`
2. Start **Apache** & **MySQL** in XAMPP
3. Open: `http://localhost/project/app.php`
4. App auto-creates database & table — ready to use ✅

## 🌐 Deploy Online
1. Sign up at **InfinityFree.net** (free)
2. Create hosting & database → get your 4 credentials
3. Edit top 4 lines in `app.php` with your live database details
4. Upload `app.php` to `htdocs/` folder
5. Visit your URL — done! 🎉
